# ActuarialMath
A mathematical package for solving actuarial problems.
This package is meant to be a lightweight collection of functions that computes
standard case values for actuarial mathematics. The package currently only
computes discrete present and future value factors of interest schemes. This
package uses no external libraries, so no dependencies are required.

INSTRUCTIONS FOR USE:
1. Download actuarial_math.py and am_api.py
2. type python am_api.py in your terminal
